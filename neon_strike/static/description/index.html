NEON STRIKE

Shooter espacial arcade dentro de tu Odoo 19 · built on Odoo

Gameplay completo

4 tipos de enemigos con IA distinta, un jefe cada 4 oleadas, power-ups, combos hasta x15, partículas, screen shake y slow-motion.

Audio sintetizado

Disparos, explosiones y power-ups generados con Web Audio API. Cero archivos de sonido, cero dependencias.

Leaderboard vía ORM

Cada partida se guarda en neon.strike.score. Todos los usuarios de la instancia compiten en el mismo marcador.
